Hand Presenter — Test Deck

This page behaves like PowerPoint's slideshow keys:

  • Fast flick left / right (any finger pose) → change slide
  • Move your hand → pointer follows it
  • Hover the PEN box in the camera window ~1s (it fills up) → drawing mode on/off
  • Drawing mode: touch thumb + index dots together = draw; hover ERASE box = clear ink; flicking is disabled
  • Open palm, hold 2s → black screen on/off
